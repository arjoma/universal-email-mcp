# Security policy

universal-email-mcp handles mailbox credentials and untrusted mail content, so
security reports are very welcome.

## Reporting a vulnerability

Please report vulnerabilities **privately** through GitHub:
[Report a vulnerability](https://github.com/arjoma/universal-email-mcp/security/advisories/new)
(Security tab → "Report a vulnerability"). Do not open a public issue.

Helpful details: affected version or commit, run mode (local / remote), steps or
a crafted message that reproduces the problem, and the impact you see (for
example credential exposure, data exfiltration through rendered output, a mail
that makes the assistant act on its instructions, SSRF).

We aim to acknowledge reports within a week and will coordinate a fix and
disclosure with you.

## Supported versions

The project is in early development (0.0.x). Fixes go into `main` and the next
release; older releases are not patched.
